# Student Database Management System

## Description
This is a Python-based Student Database Management System that helps to manage student records digitally. It can add, view and delete student information.

## Features
- Add Student Details
- View All Students
- Delete Student Record
- SQLite Database
- Roll No Validation

## Tech Stack
- Python
- SQLite3

## How to Run
Run command: python main.py
